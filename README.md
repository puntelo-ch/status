# Puntelo Status

Quelle der öffentlichen Statusseite https://status.puntelo.ch und des Alarms mit Quittung für den Betrieb von [Puntelo](https://www.puntelo.ch).

- Der Code kommt aus `infra/status` im (privaten) Hauptrepository und wird mit `infra/status/publish.sh` hierher übertragen. Bitte hier nur Meldungen ändern.
- **Störung oder Wartung melden:** eine Datei in [`meldungen/`](meldungen/) anlegen, Anleitung dort. Nach dem Speichern ist die Meldung in 1 bis 2 Minuten auf der Seite.
- Die Seite zeigt den Zustand der Website, der Verwaltung und der Online-Buchung, wie ihn UptimeRobot alle 5 Minuten von aussen misst. Sie enthält keine Personendaten und lädt nichts von fremden Servern.
